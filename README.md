# dsh-soulcore-kit（beta）

DSH 里的「大肥鱼」记忆套件：五个包 + 一份中文操作说明。

- dsh-soulcore：记忆本体（原文层、长期记忆、准入打分、隔离区、注入、星图）
- dsh-organs：器官（情绪、表达、状态、心跳、主动开口）
- dsh-qq-bridge：QQ 接入（收消息、认人、出站、表情包、语音）
- dsh-qq-stack：NapCat 托管（五环诊断、二维码、保活）
- qq-agent-presets：QQ 场景预设

装法、首次配置、没有向量服务时怎么降级，见 Release 附件里的 README-操作说明.md。

> beta：只在作者那台机器上跑过两个月。装之前先备份 DSH，出问题能退回去。
